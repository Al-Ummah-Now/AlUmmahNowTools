# Injection Security Audit — AlUmmahNowTools

| Component | Input | Risk | Status | Test |
| --- | --- | --- | --- | --- |
| `ShellBrowserLauncher.Open` (`AlUmmahNow.ToolsCore`) | Browser launch `Uri` | Arbitrary command/file/scheme execution via `ProcessStartInfo { UseShellExecute = true }` | Fixed — enforces `ShellBrowserLauncher.IsAllowedUri` (absolute `https://` or loopback `http://`, no userinfo, no control chars) | `AlUmmahNow.ToolsCore.Tests/InjectionAuditTests.cs::ShellBrowserLauncher_RejectsUnsafeSchemesAndUserinfo` |
| `LoopbackRedirect.WaitAsync` (`AlUmmahNow.ToolsCore`) | Local OAuth callback HTTP request line | Non-GET method or control chars accepted on loopback callback | Fixed — requires `GET` method, exact `/auth/callback` path, and rejects control chars | `AlUmmahNow.ToolsCore.Tests/InjectionAuditTests.cs::LoopbackRedirect_RejectsPostAndControlChars` |
| `AdminApiClient`, `ImportApiClient`, `ImportApiClient.Sources` (`AlUmmahNow.ToolsCore`) | `batchId`, `itemId`, `stagingId`, `sourceId`, `channelId`, `jobId`, `fileId`, rendition `<rung>/<file>`, `AppLocale` header, 3xx redirects | URL path traversal via `.`/`..` segments; origin escape via `new Uri(_base, path)`; cross-origin redirect leaking `Bearer` token; CR/LF injection in `X-App-Locale` | Fixed — default `HttpClientHandler` sets `AllowAutoRedirect = false`; `SafePathSegment` rejects dot-only/separator/control segments; `ResolveSameOrigin` enforces same-origin + secure scheme; `PutRenditionFileAsync` validates two-segment `<rung>/<file>`; `AppLocale` rejects control chars | `AlUmmahNow.ToolsCore.Tests/InjectionAuditTests.cs::ImportApiClient_BlocksTraversalOriginEscapeAndInvalidRenditionPath` |
| `TusClient`, `TakeoutUploader`, `UploadStep` (`AlUmmahNow.ToolsCore`) | `endpoint`, server-returned `Location`, server-returned `TusUploadId`, `metadata` keys, 3xx redirects | SSRF / credential leakage to cross-origin or cleartext TUS URL; raw `TusUploadId` path traversal/authority escape; `Upload-Metadata` key injection | Fixed — `AllowAutoRedirect = false`; `IsSafeNetworkUri` + exact `SameOrigin` on `Location`; `IsValidMetadataKey` enforced in `EncodeMetadata`; `TusClient.ResolveUploadUrl` validates `TusUploadId` in `TakeoutUploader` and `UploadStep` | `AlUmmahNow.ToolsCore.Tests/InjectionAuditTests.cs::TusClient_BlocksCrossOriginLocationTraversalUploadIdAndBadMetadataKeys` |
| `TakeoutExport.Read` (`AlUmmahNow.ToolsCore`) & `FileScanEngine` (`AlUmmahNow.FileScanService`) | Symlinks/reparse points inside Takeout export or scanned video folders | Symlink escape reading `.csv` or media files outside the selected folder | Fixed — added `FileAttributes.ReparsePoint` skip on Takeout `*.csv` enumeration and `FileScanEngine` file/directory traversal | `AlUmmahNow.ToolsCore.Tests/InjectionAuditTests.cs::TakeoutExport_SkipsSymlinkedCsvFiles` |
| `StagedPackage.Prepare` & `UpdateService` (`AlUmmahNow.ToolsCore`) | Update package `fileName`, manifest `release.Version` / `_arch` | Path traversal outside private update staging/download directory | Fixed — rejects empty, `.`, `..`, path separators, and NUL in `StagedPackage.Prepare` and `UpdateService` package filename | `AlUmmahNow.ToolsCore.Tests/InjectionAuditTests.cs::StagedPackage_RejectsTraversalFileNames` |
| `DiagnosticLog.ScrubLine` & `DiagnosticLog.Build` (`AlUmmahNow.ToolsCore`) | Log `entry.Code` and `entry.Text` containing CR/LF/C0/DEL/U+2028/U+2029 | Log line forging in diagnostic uploads | Fixed — neutralizes all C0/DEL/U+2028/U+2029 control characters and scrubs `entry.Code` | `AlUmmahNow.ToolsCore.Tests/InjectionAuditTests.cs::DiagnosticLog_NeutralizesControlCharsInCodeAndText` |
| `CsvField.Escape` & `AnalyticsDashboardViewModel.GenerateCsvReport` (`AlUmmahNow.ToolsCore`, `AlUmmahNow.VisualImporterUno`) | Channel name, priority label, file sizes in exported CSV | CSV injection / spreadsheet formula injection (`=`, `+`, `-`, `@`, `\t`, `\r`, `\n`, leading whitespace) and unquoted commas/newlines | Fixed — `CsvField.Escape` applies RFC 4180 quoting and prefixes formula triggers with `'` (preserving finite negative numbers) | `AlUmmahNow.ToolsCore.Tests/InjectionAuditTests.cs::CsvField_NeutralizesFormulasAndPreservesNumbers` |
| `FFmpegManagerService.RunProcessAsync`, `FfmpegMediaProbe.ExtractFrameAsync` (`AlUmmahNow.Data`), `FileScanServiceManager` (`AlUmmahNow.VisualImporterUno`) | External `ffmpeg`/`ffprobe`/`dotnet` process arguments, scale dimensions | Argument splitting / filter injection | Fixed — uses `ProcessStartInfo.ArgumentList` with `UseShellExecute = false`; validates `width > 0 && height > 0` before `-vf scale=...` | `AlUmmahNow.ToolsCore.Tests/InjectionAuditTests.cs` + `AlUmmahNow.Tests` |
| `ImportDbSchema` & `ImportDbContext` (`AlUmmahNow.Data`) | EF Core queries and SQL Server schema upgrade steps | SQL injection | OK — all runtime queries use EF Core LINQ with parameterized queries; `ImportDbSchema.ExecuteSqlRawAsync` runs only compile-time constant DDL strings | Codebase audit |
| `UpdateBar` & `ForcedUpdateView` (`AlUmmahNow.VisualImporterUno`) | Browser launch via `Windows.System.Launcher.LaunchUriAsync` | Unsafe URL scheme | OK — requires `UriKind.Absolute` and `uri.Scheme == Uri.UriSchemeHttps`, and `UpdateService` returns only compiled-in `DownloadPage` | Codebase audit |
| `FolderScanner` & `WorkFiles` (`AlUmmahNow.ToolsCore`) | Folder scanning and work folder cleanup | Symlink escape / arbitrary file deletion | OK — `FolderScanner` skips `ReparsePoint`; `WorkFiles` enforces 32-hex GUID IDs, exact full-path match under root, and rejects symlinks/junctions at 3 ancestor levels | Existing `AlUmmahNow.ToolsCore.Tests` |
